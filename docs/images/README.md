# Product screenshots

These images show the plugin's production Ask composer and response renderer in
the native Obsidian desktop app, using a separate demo vault and synthetic note
and response text. They contain no private notes, account data, or live agent
conversation. The desktop captures do not establish native mobile coverage.

The `floating-*.png` images show the production floating components in native
Obsidian 1.15.1, using the isolated floating-panels lab and synthetic API data.
They show Send, Ask, workspace, PR overview/checks, the minimized icon and a
430 px desktop window with native sidebars collapsed. The lab sends no prompts
and removes its synthetic note and panels after capture. These are component
rendering checks; they do not establish live account integration, native iOS
behavior or a mobile keyboard layout.
