# Ask Queue

## Collect questions

Select text, open **Ask Agent**, enter a question, and choose **Add to Ask Queue**.
The queue holds a snapshot of each selection and question on this device. It
does not start an agent. **Review Ask Queue** shows the entries for the current
note. Edit, remove, or reorder them, then choose **Send combined questions…**.
Use the normal destination chooser to send one prompt and get one reply at the
end of the note. Entries are removed only after a successful send. Cancelled
destination selection and failed sends retain them. The queue is bounded to 32
entries and does not sync between devices.
